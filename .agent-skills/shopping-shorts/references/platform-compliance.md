# Platform and Commercial Disclosure Contract

확인 기준일: 2026-09-01 KST. 공개 직전 공식 페이지를 다시 확인한다. 플랫폼 규정과 현지 법은 독립적으로 모두 적용될 수 있다. 프로그램별 조사·freshness·공식 URL 계약은 `commerce-platform-research.md`, Instagram·TikTok·X의 근거는 `social-platform-research.md`가 소유한다.

## YouTube YPP and Shopping eligibility

YPP는 YouTube Partner Program이다. 현재 한국은 두 단계로 구분한다.

- Expanded YPP: 구독자 500명 + 최근 90일 공개 업로드 3개 + 3,000 유효 시청시간 또는 300만 유효 Shorts 조회수. 팬 펀딩·Shopping 조기 접근 단계.
- 광고수익 단계: 구독자 1,000명 + 4,000 유효 시청시간 또는 최근 90일 1,000만 유효 Shorts 조회수. Shorts 피드 시청시간은 4,000시간에 포함되지 않음.

기준 충족만으로 자동 승인되지 않으며 광고수익과 Shopping 제휴 자격은 별도다. 시행일이 2027년인 변경은 현재 run에 적용하지 않는다.

## YouTube Shopping eligibility

공식 문서: https://support.google.com/youtube/answer/13376398?hl=ko

대한민국은 YouTube Shopping 제휴 프로그램 지원 국가다. 그러나 제품 태그는 모든 채널에 자동 제공되지 않는다. 공식 문서의 최소 자격에는 다음이 포함된다.

- 채널이 YouTube 파트너 프로그램에 가입됨.
- YPP 구독자 기준 충족.
- 지원 국가 거주.
- 음악 채널 또는 공식 아티스트 채널이 아님.
- 채널이 아동용이 아니고 아동용 영상이 많지 않음.

자격 기준은 파일럿에 따라 달라질 수 있다. 하네스는 로그인된 YouTube Studio의 현재 상태를 진실원으로 본다.

운영 판정:

- 모두 확인: `commerce-ready`.
- 하나라도 미확인: `creative-only`.
- 자격 없음: 쇼핑 태그를 계획에 넣지 않음. 외부 제휴 링크를 쓰려면 해당 제휴사 등록·고지 규칙을 별도로 확인.

## Authentic and non-mass-produced content

공식 문서: https://support.google.com/youtube/answer/1311392?hl=ko

YouTube 수익 창출 정책은 자체 제작한 진정성 있는 콘텐츠를 요구하며, 대량 생산되거나 일반적이거나 중복되거나 조작된 콘텐츠를 금지한다.

하네스 적용:

- 한 실행당 최종 영상 최대 한 편.
- 여러 상품에 같은 대사·컷·가상인물·배경을 자동 대입하지 않음.
- 비슷한 영상 묶음 대신 하나의 시청자 문제와 하나의 검증 가능한 관점을 명시.
- 채널 단위로 최신 영상의 구조가 반복되는지 독립 검수.
- “AI가 만들었다”는 사실만으로 독창성이 생긴다고 보지 않음.

## Generative AI disclosure

공식 문서: https://support.google.com/youtube/answer/14328491?hl=ko

YouTube는 실제와 분간하기 어려운 장면을 생성하거나 의미 있게 변경한 경우 `AI 사용` 공개를 요구한다. 실제로 발생하지 않은 장면을 사실적으로 생성하는 제품 시연은 공개 대상이다.

공개가 보통 필요 없는 제작 보조 예시:

- 아이디어, 개요, 스크립트, 제목, 썸네일 생성.
- 자막 생성.
- 선명화·업스케일·오디오 복원.
- 비현실적인 애니메이션.

하네스 기본값:

- 제품이 현실 공간에서 작동하는 AI 생성 장면: `youtube_ai_disclosure: yes`.
- 단순 문안·자막 보조만 AI 사용: 상황을 기록하되 자동으로 `yes`를 강제하지 않음.
- 애매하면 실제와 오인될 가능성을 독립 검수하고 보수적으로 표시.

AI 표시를 했다는 이유만으로 제품 기능 발명이나 허위 시연이 허용되는 것은 아니다.

## Paid promotion on YouTube

공식 문서: https://support.google.com/youtube/answer/154235?hl=ko

유료 PPL, 스폰서십, 직접 광고 또는 공개해야 하는 상업적 이해관계가 있으면 YouTube Studio의 유료 프로모션 항목을 설정해야 한다. YouTube 공개는 현지 법상 추가 고지를 대체하지 않는다.

금지 유료 프로모션 예시에는 불법 서비스, 성인 콘텐츠, 기분전환용 약물, 규제 의약품, 미검토 도박, 시험 부정행위, 해킹·피싱·스파이웨어, 폭발물, 허위·혼동 비즈니스가 포함된다. 이 목록은 전부가 아니므로 고위험 범주는 공개 전에 현재 정책을 다시 확인한다.

## Instagram compliance

- Reels의 paid partnership·affiliate 관계는 플랫폼 Paid partnership label과 한국 경제적 이해관계 고지를 함께 적용한다.
- Content Publishing API는 shopping tags를 지원하지 않는다. 자동 게시 성공을 제품 태그 성공으로 읽지 않는다.
- 포토리얼 영상 또는 실사형 음성의 생성·중대 변형은 Instagram AI label 대상이다.
- Bonuses는 invite-only이고 branded content는 earning 대상에서 제외된다.

## TikTok compliance

- Branded Content Policy상 선물·대가·affiliate link·promotion code 관계는 commercial content disclosure 대상이다.
- 제3자 브랜드는 Paid partnership label, 본인 브랜드는 Promotional content label을 적용하고 제품·서비스를 영상 또는 캡션에서 명확히 밝힌다.
- 현실적인 AIGC에는 AI label을 적용한다. Content Posting API에서는 `is_aigc`와 commercial toggles를 함께 봉인한다.
- Creator Rewards는 1분 이상이며 광고·유료 프로모션·협찬 콘텐츠가 부적격이다. 쇼핑 영상에 보상 적격을 약속하지 않는다.
- commercial content toggle과 별개로 현재 한국 industry-entry 표에서 상품·서비스 카테고리의 금지·제한·증빙 조건을 확인한다. `tiktok-kr-category-screen` 문자열만 쓰지 않고 공식 source·`allowed` 판정·KST 시각·검수자·화면 이미지 SHA-256을 `compliance_evidence`에 묶는다.
- audited client·`video.publish` scope·creator consent·privacy selection·공개 read-back이 없으면 자동 공개하지 않는다.

## X compliance

- affiliate link·discount code·선물·대가 관계는 X Paid Partnership disclosure 대상이다.
- Creator Revenue Sharing 은퇴와 Original Content Rewards rollout을 날짜별로 분리한다.
- Original Content Rewards는 automated means로 생성·게시된 콘텐츠가 부적격이다. X API로 게시 가능하다는 사실을 보상 적격성으로 승격하지 않는다.
- 영상 프리롤 광고·sponsorship graphic은 X의 별도 사전 동의 없이 사용하지 않는다. Paid Partnership label은 이 동의를 대체하지 않는다. `x-third-party-video-ad-screen`은 `not-present|consent-confirmed` 판정과 공식 source·KST 시각·검수자·화면 이미지 SHA-256이 있을 때만 유효하다.
- X API 가격은 동적 관측치이며 외부 링크 포함 Post의 현재 비용을 공개 직전 Developer Console에서 다시 확인한다.
- 웹사이트 scripting 같은 비API 자동화를 사용하지 않는다.

## Korean endorsement disclosure

현행 심사지침 진실원:

- https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000190311
- YouTube 공식 페이지가 연결하는 공정위 자료: https://www.ftc.go.kr/www/selectReportUserView.do?key=10&rpttype=1&report_data_no=8706

경제적 이해관계가 추천·보증 내용이나 신뢰도에 영향을 미칠 수 있으면 소비자가 쉽게 인식하도록 표시한다.

한 문구를 모든 제휴사에 재사용하지 않는다. 선택 경로의 현재 공식 문구를 `strategy/commerce-route.json.required_disclosures`에 고정한다. 예를 들어 쿠팡 공식 가이드의 권장 문구는 다음과 같다.

```text
이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
```

상황에 맞춰 `광고`, `유료광고`, `협찬`, `제품 제공`, `본인 브랜드`를 정확하게 사용한다. 실제 경제적 관계를 조건부이거나 모호한 표현으로 낮추지 않는다.

고지는 다음 두 표면에 둔다.

1. 쇼츠 화면에서 시청자가 놓치기 어려운 위치와 시간.
2. 설명란 첫부분 또는 플랫폼이 요구하는 명확한 위치.

해시태그 더보기 뒤, 고정 댓글만, 작은 회색 글자, 빠르게 사라지는 문구는 단독 고지 수단으로 사용하지 않는다.

## Korean affiliate route specifics

### Coupang Partners

- 링크가 들어가는 모든 활동 페이지·채널 등록과 최종승인을 구분한다.
- 미등록 매체는 `commerce-ready`가 아니다.
- `링크를 클릭하세요` 같은 클릭 유도, 자동 클릭·노출, 자기 구매를 금지한다.
- 노출수·클릭수·CTR 등 제한된 리포트 지표를 공개 콘텐츠에 넣지 않는다.
- 상품 이미지·로고·API 데이터를 내려받아 변형할 권리가 별도로 확인되지 않으면 G2 FAIL.

### Zigzag

- 공유리워드, 크리에이터 라운지, YouTube Shopping 연동을 서로 다른 프로그램으로 기록한다.
- 요율·부스트·캠페인·2차 활용 조건은 동적이며 현재 앱·캠페인 상세가 진실원이다.
- 일반 공유 링크와 리워드 링크를 혼동하지 않고, 판매자 Open API를 크리에이터 자동화 API로 오인하지 않는다.

### Naver Clip and Shopping Connect

- 클립 크리에이터 선발, 클립 광고 인센티브, 쇼핑 커넥트를 분리한다.
- 광고 인센티브와 달리 쇼핑 커넥트에는 구독자 수 제한이 없지만 브랜드 커넥트 가입·약관 동의·동일 ID가 필요하다.
- AI 자동 생성물을 거의 그대로 게시하거나 동일 템플릿을 단기간 대량 생산하면 수익화에서 제외될 수 있다.
- AI 활용 설정, 쇼핑 커넥트 태그의 자동 광고 표시, 고정댓글 등 현재 클립 전용 고지 절차를 별도로 확인한다.
- 공식 공개 업로드·태그 API가 확인되지 않았으므로 자동 게시 가능으로 표시하지 않는다.

## AI virtual-person endorsement in Korea

공정위 공식 보도자료:

- https://www.ftc.go.kr/www/selectBbsNttView.do?bordCd=3&key=12&nttSn=47547&pageIndex=1&pageUnit=10&searchCnd=all&searchCtgry=01%2C02

공정위는 개정된 「추천·보증 등에 관한 표시·광고 심사지침」을 2026-06-01부터 시행했다. AI로 만든 가상인물이 사진·동영상에서 추천·보증하면, 가상인물이 등장하는 동안 가까운 위치에 `가상인물` 등의 문구를 표시하도록 안내한다.

하네스 적용:

- AI 인물이 단순 배경이 아니라 제품을 추천·증명·사용하면 `virtual_person.present=true`.
- 등장 전체 구간에 인접한 `가상인물` 표시.
- YouTube `AI 사용` 라벨과 경제적 이해관계 고지를 별도로 유지.
- 실제 소비자 후기처럼 말하게 하지 않음.

## Product claims

플랫폼 고지만으로 표시광고법, 전자상거래, 의료·건강·금융·식품·화장품 등 품목별 규제가 해결되지 않는다.

자동 제작 제외 기본 범주:

- 질병 진단·치료·예방 효능을 주장하는 제품.
- 투자 수익 또는 부채 해결을 보장하는 서비스.
- 도박·성인·불법·해킹·시험 부정행위.
- 아동을 직접 구매자로 겨냥한 상업 콘텐츠.
- 위험한 도구를 안전 지침 없이 시연하는 콘텐츠.
- 전후 비교를 조명·속도·편집으로 조작하는 콘텐츠.

해당 범주가 감지되면 전문 법률·규정 검토 없이 렌더하거나 공개하지 않는다.

## Release checklist

- [ ] 카탈로그의 필수 20개 프로그램 조사 파일이 complete이고 live 소스가 7일 이내.
- [ ] 선택 경로와 G0 receipt의 platform·route SHA-256 일치.
- [ ] 선택 채널의 수익 프로그램·계정·지역·매체 등록 상태를 현재 UI에서 확인.
- [ ] 게시 표면의 release adapter, API scope/audit, 플랫폼 disclosure·AI controls 지원을 확인.
- [ ] 제품 태그가 실제 영상의 제품과 정확히 일치.
- [ ] 제휴사 매체 등록, 최종승인, 링크 사용 조건 확인.
- [ ] 상품별 요율·재고·가격을 공개 직전에 재확인.
- [ ] 제휴 자산의 저장·변형·상업적 재사용 권리 확인.
- [ ] AI 생성 장면의 공개 필요 여부 판정.
- [ ] 현실적 합성 장면이면 선택 플랫폼의 AI label을 적용.
- [ ] 협찬·제휴·광고 관계에 맞는 화면 고지와 설명·캡션 고지.
- [ ] 적용 시 YouTube 유료 프로모션, Instagram Paid partnership, TikTok commercial content와 KR category screen, X Paid Partnership과 third-party video ad screen을 각각 사용.
- [ ] 가상인물 추천이면 등장 동안 인접 라벨.
- [ ] 생성 클립에 모델 합성 글씨·자막·워터마크가 없고 실제 제품 표시는 보존됨.
- [ ] 조립 자막이 typewriter·최대 2줄이며 실제 폰트·burn-in·세이프 에어리어를 전체 재생으로 확인.
- [ ] 상품의 모든 material claim이 evidence ledger와 일치.
- [ ] 대량생산·반복 템플릿이 아님.
- [ ] 정확한 채널·파일·제목·설명·태그·비용을 최종 확인받음.
- [ ] 공개 후 URL, 라벨, 설명, 제품 태그를 다시 읽어 검증.
