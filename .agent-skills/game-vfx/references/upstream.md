# Reference boundary

This skill is an original, engine-neutral workflow. It does not ship engine code, game assets, shaders, or copied upstream implementation.

The numerical starting points in `SKILL.md` are adaptation heuristics from the project research that motivated this skill. Treat them as profiling prompts, not universal limits. Replace them with measured budgets for the target engine, device, resolution, and quality tier.

Use the target engine's official documentation for renderer APIs, shader syntax, post-processing, particle pooling, and accessibility settings. Keep the effect specification and the measured capture together so later tuning can distinguish a design change from a renderer change.
