MR Office är en AI-kontorssvit för riktiga filer: Word, Excel, PowerPoint och PDF, på webben och i en gratis skrivbordsapp, med en AI bredvid varje dokument och direktsamredigering. Det här repot publicerar källkoden för dess redigerare: samma redigerare som MR Office kör, som du kan bygga, köra och bädda in själv.

## Gratis för privatpersoner och små team

- **MR Office online och skrivbordsappen** — gratis: riktig redigering av Word, Excel, PowerPoint och PDF, direktsamredigering och delning, på webben, i mobilen och offline på din dator. AI ingår med en gratis daglig kvot; tyngre AI-användning är en valfri betalplan.
- **Inbäddningen, för din egen app** — gratis att börja med, allt ingår: den fullständiga formelmotorn, riktiga Office-filer, samredigering, alla exportformat och automatiserings-API:et (1 000 sessioner i månaden på localhost, 100 på dina egna domäner, upp till 2 appar, inget kort).
- **Företag med tyngre användning** — betala efter användning på en fullt hostad tjänst: Starter för US$29 i månaden med 5 000 sessioner, Pro för US$149 i månaden med 40 000 sessioner, white-label och prioriterad support. Ingen årslicens, inga servrar att driva, inga uppgraderingar att hantera: uppdateringar, skalning och säkerhetskopior sköter vi.

## AI som arbetar inuti dina filer

I MR Office arbetar AI:n på själva dokumentet, inte på text som klistrats in i en chatt. Den läser filen, gör ändringen i filens egna objekt och visar vad den rört innan du behåller den.

- **Copilot i varje redigerare** — dokument, kalkylblad, presentationer, PDF och kod. Markera eller ringa in det du menar och säg vad du vill: den redigerar stycken, tabeller, celler och formler, former och bilder på plats, frågar när begäran är otydlig, förhandsgranskar ändringen innan den sparas, och varje ändring kan ångras.
- **Ändringar du granskar** — det AI:n föreslår tillämpas först när du bekräftar det; om filen ändrats under tiden blir förslaget ogiltigt och inget du skrivit skrivs över.
- **Ett AI-fönster som känner din arbetsyta** — fråga om dina filer, anteckningar och din canvas och få svar som anger sina källor; den utformar nya dokument, kalkylblad och presentationer, och bygger ett litet verktyg på canvasen när du behöver ett.
- **Minne** — en minnesgraf håller reda på personerna, projekten och besluten som spelar roll, så att AI:n inte börjar från noll i varje konversation.
- **Ledande modeller** — välj modell för varje konversation bland dagens ledande AI-modeller; dina filer stannar på din arbetsyta, eller på din egen dator med skrivbordsappen.

### Låt din AI-agent redigera Office-filer (MCP)

Claude, ChatGPT, Cursor, Codex, VS Code och alla andra MCP-klienter kan skapa, öppna, redigera, läsa tillbaka, avbilda och exportera dokument och kalkylblad via MR Office MCP-server (`create_document`, `open_document`, `update_document`, `get_document`, `render_page`, `export_document` till docx, xlsx, pptx, pdf, md, html eller csv). I appar som visar MCP Apps visas redigeraren direkt i konversationen; på andra ställen svarar verktygen med en länk till samma redigerare och en bild av sidan. Du och AI:n redigerar samma dokument: assistenten läser tillbaka dina ändringar innan den fortsätter, och en uppdatering som görs ovanpå ändringar den inte har sett avvisas i stället för att gå förlorad.

```bash
# Claude Code
claude mcp add mroffice -- npx -y mroffice-mcp
# Codex
codex mcp add mroffice -- npx -y mroffice-mcp
```

Claude Desktop, Cursor och andra appar som tar en JSON-konfiguration:

```json
{ "mcpServers": { "mroffice": { "command": "npx", "args": ["-y", "mroffice-mcp"] } } }
```

Ingen installation: anslut den hostade endpointen `https://mcp.mroffice.ai/mcp` och logga in med ditt MR Office-konto. Word-, Excel- och PowerPoint-filer går genom MR Office Office-motor som ditt eget konto; MCP-serverns källkod finns i `apps/mcp`. [MCP-guide →](https://mroffice.ai/sv/developers/mcp)

### Bädda in redigerarna i din webbapp (rekommenderas)

MR Office tillhandahåller redigerarna; din server signerar en kortlivad sessionstoken och din sida öppnar redigeraren. Den redigerar riktiga Word-, Excel-, PowerPoint- och PDF-filer (.docx, .xlsx, .pptx, .pdf), med den fullständiga formelmotorn, samredigering, uppladdningar, alla exportformat, utskrift, automatiserings-API:et (dokumentobjektmodell, makron, plugin-program) och sparanden som skickas tillbaka till din server i en signerad callback. Allt ingår i Free-planen: 1 000 sessioner per månad på localhost, 100 på dina egna domäner, upp till 2 appar, inget kort behövs. Som en hostad tjänst lägger den inga AGPL-skyldigheter på din egen app.

1. Kör `npx mroffice-embed init` i projektets mapp (eller skapa en app i utvecklarkonsolen): ett klick på "Tillåt" i webbläsaren, så skrivs appens nycklar till `.env.local` / `.env`.
2. Din server skapar en sessionstoken med `createSessionToken` från `mroffice-embed/server`; den hemliga nyckeln lämnar aldrig servern.
3. Din sida öppnar redigeraren med `open()` från `mroffice-embed` (eller skriptet `https://mroffice.ai/embed/v1/embed.js`).

```js
// server: GET /api/mroffice/session (check who is signed in first)
import { createSessionToken } from "mroffice-embed/server";
const token = await createSessionToken({
  appId: process.env.MROFFICE_APP_ID,
  secretKey: process.env.MROFFICE_SECRET_KEY, // mro_sk_..., server only
  file: { key: "contract-42", name: "contract.docx", url: signedUrlToTheFile },
  user: { id: user.id, name: user.name },
  mode: "edit",
});

// page
import { open } from "mroffice-embed";
open({ container: "#editor", token: () => fetch("/api/mroffice/session").then((r) => r.json()).then((b) => b.token) });
```

## Redigerarna

Vad varje redigerare gör i det här arkivet:

- **Dokument** — en sidindelad ordbehandlare: teckensnitt, styckeformatering, listor och stilar på Start; omslags- och tomma sidor, sidbrytningar, tabeller, bilder, former, SmartArt, diagram, länkar, bokmärken, kommentarer, sidhuvuden, sidfötter och sidnummer, ekvationer, symboler, textrutor och WordArt på Infoga. Sparar sitt eget format (.mrdoc); öppnar HTML, Markdown och oformaterad text.
- **Kalkylblad** — celler och formler med teckensnitt, justering, talformat, villkorsstyrd formatering, cellformat och infoga eller ta bort celler på fliken Start; tabeller, bilder, former, ikoner, kryssrutor, diagram och miniatyrdiagram på fliken Infoga; flera blad, med summor och medelvärden för markeringen. Aritmetik mellan celler (=A1*B1+10) beräknas live i webbläsaren medan du skriver, och varje formel som en fil innehåller bevaras intakt; den fullständiga formelmotorn (SUM, IF, VLOOKUP och hundratals fler) körs gratis i MR Office-skrivbordsappen och i den hostade inbäddningens Free-plan. Sparar i sitt eget format (.mrsheet); öppnar och sparar CSV och TSV.
- **Presentationer** — bilder med layouter och avsnitt, text, teckensnitt och stycken, och former med deras arrangemang på Start; tabeller, bilder, ikoner, SmartArt, diagram, textrutor, WordArt, sidhuvuden och sidfötter, ekvationer, symboler och video på Infoga; talarnoter, kommentarer och presentation. Sparar sitt eget format (.mrslides).
- **PDF** — läs, presentera och skriv ut PDF-filer: enkel- och tvåsidiga vyer, kontinuerlig rullning, rotation, miniatyrbilder och läsläge, sökning och kopiering av deras text, samt kommentarer; redigering av en PDFs egen text och spara tillbaka den i filen är gratis i MR Office-skrivbordsappen och den hostade inbäddningen.
- **Kod** — en snabb kodredigerare med syntaxmarkering för många språk, en disposition, sök, snabböppning, en filutforskare och en problemlista.

Formler med funktioner (SUM, IF, VLOOKUP och hundratals fler), Word-, Excel- och PowerPoint-filer, diagram, SmartArt och automatiserings-API:et är gratis att använda: i den kostnadsfria MR Office-skrivbordsappen, och i din egen app via den hostade inbäddningens Free-plan. Filer behåller varje formel, diagram och SmartArt intakt även i de öppna källkodsredigerarna.

## Kör redigerarna

**▶ [Prova livedemon – ingen installation](https://mroffice.ai/sv)**

De fem redigerarna finns i `packages/` (`@mrnote/docs`, `sheets`, `slides`, `pdf`, `code`, som delar `@mrnote/core`) och körs tillsammans i `apps/playground`:

```bash
npm install
npm run fonts     # the open substitutes for Office's fonts
npm run build
npm run preview   # http://localhost:5178
```

`npm run dev` startar en utvecklingsserver på samma adress och `npm run smoke` kontrollerar ett bygge. Varje pakets README beskriver i detalj vad det gör och hur det bäddas in.

## Skrivbordsapp

[`apps/desktop`](../apps/desktop) innehåller **MR Office Editors**: källkoden för skalet i MR Office skrivbordsapp (Electron), under en egen identitet. Med den kostnadsfria MR Office-komponenten från Releases är det MR Office skrivbordsapp, med Word-, Excel-, PowerPoint- och PDF-filer, inloggning och AI. Utan komponenten kör den de öppna källkodsredigerarna på egen hand, som öppnar .mrdoc-, .mrsheet- och .mrslides-filer, CSV, HTML, Markdown och PDF. Skalet och redigerarna är AGPL-källkod; komponenten är en kostnadsfri nedladdning från Releases. Efter `npm run build`, starta den med:

```bash
npm run desktop
```
