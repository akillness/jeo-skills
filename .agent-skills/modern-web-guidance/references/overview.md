# Modern Web Guidance Overview

`modern-web-guidance` provides standardized, Google Chrome DevRel-curated web platform best practices for AI agents and engineers.

## Guidance Domains (17 Categories)

| Category | Description | Primary Capabilities |
|---|---|---|
| `accessibility` | Inclusive web design standards | ARIA patterns, focus management, screen-reader semantics, color contrast |
| `built-in-ai` | Browser-native AI APIs | Summarization, Translation, Prompt API, Writer & Rewriter APIs |
| `css` | Modern CSS platform standards | Container queries, anchor positioning, view transitions, scroll-driven animations, nesting |
| `forms` | Input, validation & UX | Custom selects, constraint validation, autofill, accessible form controls |
| `html` | HTML5 semantic primitives | `<dialog>`, `<popover>`, `<details>`, `<table>`, responsive pictures |
| `js` | Client-side JavaScript APIs | Temporal date/time, sanitization (`Sanitizer` API), Web Workers, BroadcastChannel |
| `performance` | Core Web Vitals (CWV) | LCP optimization, INP responsiveness, CLS stability, `fetchpriority`, `content-visibility` |
| `privacy` | User privacy & tracking protection | Storage Access API, Private State Tokens, partitioned cookies (CHIPS) |
| `pwa` | Progressive Web Apps | Web App Manifest, Service Workers, install prompts, badging, background sync |
| `security` | Modern web security | Passkeys / WebAuthn, Content Security Policy (CSP), Trusted Types, COOP/COEP |
| `ui-atoms` | Micro-interaction primitives | Tooltips, badges, loaders, avatars, icons, switches |
| `ui-behaviors` | Dynamic UI interaction patterns | Light dismiss, infinite scroll, pull-to-refresh, keyboard shortcuts, trap focus |
| `ui-components` | Compound UI patterns | Accordions, carousels, bottom sheets, navigation bars, multi-step wizards |
| `user-experience` | Overall web UX hygiene | Empty states, error boundaries, skeleton loaders, undo toast notifications |
| `visual-design` | Theming and design aesthetics | Dark mode, high contrast modes, fluid typography, color spaces (oklch, display-p3) |
| `wasm` | WebAssembly integration | Rust/C++ compiles to Wasm, streaming instantiation, SIMD, threads |
| `webmcp` | Web Model Context Protocol | Browser-to-agent tool bindings and contextual model bridges |
