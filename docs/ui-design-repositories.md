## Installation and operation boundary

Preview only, from a trusted checkout or installed router:

```sh
python3 -B .agent-skills/jeo-skill/scripts/jeo-skill.py install --bundle ui-design-repositories --dry-run
```

An approved catalog install copies the ten guide folders and support files. It does not
approve npx/npm/Bun execution, component copying, dependency or CSS changes, registration
of MCP/remote endpoints, browser flags, prompt/screenshot uploads, accounts, purchases,
publishing or deployment. Select one named source and inspect its reference first.
Hyperiux's `add --dry-run` still accesses auth/registry state; do not conflate it with the
catalog router's offline selection preview.

For Canvas UI reusable-kit/component redistribution, Hyperiux standalone effect/registry
distribution, or Cursify copying without an applicable grant, stop that reuse path and
obtain the required permission or choose an appropriately licensed alternative. Other
sources retain copyright/notice obligations; software licenses do not automatically clear
third-party logos, demo photographs, fonts or product claims.

## Verification scope

Per-skill `evals/evals.json` files contain authored positive and negative scenarios.
They are **not executed model-quality evaluations**, browser tests or compatibility scores.
`python3 -B scripts/test_ui_design_skills.py -v` exercises offline source-map, packaging,
metadata, independent-support and inert bundle-selection invariants only. It cannot prove
that an upstream effect renders, has no leaks, meets accessibility standards or is fast.

All future UI integrations must verify the actual consuming route, including static fallback,
keyboard/touch/focus, reduced motion, resize/reflow and mount/unmount cleanup where relevant.
Source-specific caveats and stop conditions remain in each independently installable guide.
Transient local command outcomes and exact-SHA publication/Actions receipts belong outside
the repository in `JEOPI_RESULT.md`, not in these reusable operator instructions.
